# W-States

$$
|W_n\rangle = \frac{|10...0\rangle + |01...0\rangle + ... + |00...1\rangle}{\sqrt{n}} = \sqrt{\frac{n-1}{n}} |0\rangle|W_{n-1}\rangle + \frac{1}{\sqrt{n}}|1\rangle|0^{\otimes n - 1}\rangle
$$

$$
\sin{\frac{\theta}{2}} = \frac{1}{\sqrt{n}} 
$$

$$
\theta = 2\arcsin{\frac{1}{\sqrt{n}}}
